# Тестовое задание Junior Data Analyst: продажи и запасы электротехники

## Структура

| Путь | Что внутри |
|---|---|
| `data/` | Исходные CSV, не изменялись |
| `sql/solution.sql` | **Диалект DuckDB.** Загрузка, проверки качества, очистка, выгрузки, топ-3 OVERSTOCK |
| `run_sql.py` | Запускает `solution.sql` и создаёт `output/` |
| `forecast/forecast.py` | Проверка двух методов (WAPE), итоговый прогноз, оценка упущенных продаж |
| `analysis/actions.py` | План перемещений между складами и список докупки |
| `looker/` | `looker_data.xlsx` для Google Sheets и `LOOKER_STUDIO_GUIDE.md` с пошаговой сборкой отчёта |
| `slides/` | Презентация (PPTX и PDF) и её генератор |
| `output/` | Все результаты |

## Порядок запуска (из корня проекта)

```bash
pip install duckdb pandas openpyxl
python run_sql.py               # 1-2. проверки + sales_monthly.csv, inventory_october.csv, top3_overstock.csv
python forecast/forecast.py     # 3. forecast.csv + проверка методов
python analysis/actions.py      # действия для закупок
python looker/build_sheets.py   # 4. книга для Google Sheets
```
Если установлен DuckDB CLI, SQL можно выполнить напрямую: `mkdir output && duckdb < sql/solution.sql`.

## 2. Выгрузки
- `output/sales_monthly.csv` содержит 2592 строки (24 месяца × 36 SKU × 3 склада), месяцы без операций заполнены нулями.
- `output/inventory_october.csv` содержит 108 пар. Статусы: OK 91, OVERSTOCK 8, OOS 5, NO_SALES 2, NO_DATA 2.
- `output/top3_overstock.csv` построен через `ROW_NUMBER() OVER (PARTITION BY warehouse_id ORDER BY excess_value_kgs DESC, sku_id)`.

## 3. Прогноз (`output/forecast.csv`)

| Метод | WAPE, авг–окт 2026 |
|---|---|
| Базовый: факт того же месяца год назад | 10,09% |
| **Тот же месяц год назад × рост SKU за 6 мес. к тем же месяцам прошлого года** | **8,06%** |

Выбран второй метод. У данных устойчивая годовая сезонность (спад в январе–феврале, пик в августе–октябре) и рост примерно 9% в год. Базовый метод учитывает сезонность, но не учитывает рост. Окно роста в 6 месяцев показало лучший результат: при окне 3 мес. WAPE 8,49%, при окне 9 мес. 8,11%. Для полной модели вроде Holt-Winters двух неполных лет истории мало.

**Влияние дефицита.** В дни без остатка продажи не происходили, поэтому факт ниже спроса. По оценке, за август–октябрь 2026 упущено около 690 ед., из них 464 в октябре. Больше всего у E013 в Бишкеке (~289 шт) и E009 в Оше (`output/lost_sales_aug_oct_2026.csv`). Из-за этого октябрь 2026 оказался ниже сентября. Часть ошибки обоих методов приходится на заниженный факт, а не на сам прогноз. Итоговый прогноз построен на «зашумлённой» дефицитом истории и поэтому скорее консервативен.

Итог на 11.2026–10.2027: **122 517 ед.**, на 8,5% больше, чем за предыдущие 12 месяцев.
